# 界面语言资源

当前支持跟随系统、English、简体中文，可在设置中切换，立即生效并保存。

翻译文案位于 `assets/locales/en-US.json` 和 `assets/locales/zh-CN.json`，构建后复制到 EXE 旁同名目录。发布脚本会一并打包该目录；不要只复制 EXE。

`messages` 的键为稳定的英文源消息，值为该语言的显示文案。带数值或进程名的消息使用 `{0}`、`{1}` 等占位符；两份资源中的键和占位符集合必须一致。翻译可以调整占位符顺序。

Core 加载资源并提供查询，UI 在创建和更新文本时查询资源。切换语言时更新现有控件，保留滚动位置、选中进程和未应用的设置。未知消息或缺少资源时回退到源文案。操作系统、驱动、设备及可执行文件提供的名称保留原值。

`LocalizationTest` 校验资源完整性、占位符一致性、动态消息、语言往返切换及资源缺失时的回退行为。
